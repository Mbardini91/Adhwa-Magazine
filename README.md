# مجلة أضواء — الموقع التفاعلي

قالب ثابت للمجلة: كل عدد جديد تحط ملف الـPDF وتشغّل أمر واحد، فيتجهّز الموقع كامل.

**وظائف القارئ:** تقليب بصفحتين، أو صفحة وحدة على الجوال (وصفحتين إذا قلبه بالعرض) · سحب الصفحة بالإصبع · صوت تقليب الورق · **قراءة صوتية احترافية بصوت بحريني طبيعي** · بحث · روابط فعّالة · إعجاب بكل موضوع · اقتباس كصورة · مشاركة الموضوع · تحميل المجلة PDF · ملء الشاشة.

**الواجهة:** على الشاشات العريضة (كمبيوتر، تابلت أو جوال بالعرض) الأزرار تكون على شريطين جانبيين، والمجلة تاخذ ارتفاع الشاشة كامل. على الجوال بالطول تكون فوق وتحت، لأن العرض هناك هو المساحة الناقصة.

```
Adhwa-Magazine/
├── issue/
│   ├── issue.json          ← بيانات العدد الحالي (الرقم، العنوان، المواضيع)
│   └── Adwaa-Q2-2026.pdf   ← ملف العدد
├── tools/                  ← أداة البناء والقالب (ما تحتاج تلمسها)
│   ├── build.py
│   └── template.html
├── public/                 ← الموقع الجاهز (يتولّد تلقائياً — هذا اللي يترفع)
│   ├── index.html
│   ├── firebase-config.js  ← إعدادات مشروعك (الخطوة 4)
│   ├── likes.bundle.js     ← مكتبة Firebase (مضمّنة، بدون روابط خارجية)
│   ├── pages/ hi/ thumbs/  ← صور الصفحات
│   ├── Adwaa-19-Q2-2026.pdf← ملف التحميل (مضغوط، الروابط والنص فيه شغالين)
│   └── og-cover.jpg        ← صورة المعاينة عند مشاركة الرابط
├── firebase.json · firestore.rules · .firebaserc
```

## 🆕 نشر عدد جديد (كل ربع سنة)

تحتاج مرة وحدة: [Python 3](https://www.python.org/downloads/) ثم داخل مجلد المشروع:
```bash
pip install -r tools/requirements.txt
```

بعدها كل عدد:

1. **حط الـPDF** داخل `issue/` (احذف القديم أو خلّه، ما يفرق).
2. **عدّل `issue/issue.json`:**
   ```json
   {
     "id": "2026-q3",
     "number": 20,
     "title": "العدد 20 – الربع الثالث 2026",
     "label": "العدد 20 · الربع الثالث 2026",
     "pdf": "issue/Adwaa-Q3-2026.pdf",
     "download_name": "Adwaa-20-Q3-2026.pdf",
     "site_url": "https://PROJECT-ID.web.app",
     "topics": []
   }
   ```
   - `id` لازم يتغيّر كل عدد (حروف إنجليزية صغيرة وأرقام وشرطة). هذا اللي يخلّي **إعجابات كل عدد منفصلة**، فأرقام العدد القديم ما تنتقل للجديد.
   - خلّ `topics` فاضية `[]`.
3. **شغّل البناء:**
   ```bash
   python tools/build.py
   ```
   أول مرة يستخرج **المواضيع من فهرس المجلة تلقائياً** (من روابط صفحة الفهرس) ويحفظها في `issue.json`. افتح الملف وراجع العناوين: احذف كلمات الأقسام الزايدة مثل «عن الهيئة»، وأضف أي موضوع مو موجود في الفهرس. بعدها شغّل البناء مرة ثانية.
4. **انشر:** `firebase deploy`

> تعديل سريع (مثلاً تغيير عنوان موضوع أو القالب) بدون إعادة توليد الصور: `python tools/build.py --skip-images` (ثواني بدل دقايق).

> البناء ياخذ تقريباً 5 دقايق لعدد بـ58 صفحة.
> عشان الروابط والفهرس يشتغلون، صدّر الـPDF من InDesign مع تفعيل **Hyperlinks** و**Bookmarks**، وخلّ النص نص مو صور (Interactive أو Print بدون Flatten text).

**شكل المواضيع** (لو حبيت تعدّل يدوياً): `s` و `e` هي أرقام صفحات الـPDF (مو المطبوعة على الصفحة)، و`id` حروف إنجليزية:
```json
{"id": "zanzibar", "s": 38, "e": 43, "t": "زنجبار.. حيث يصنع العطاء أجمل الرحلات"}
```

## 🎙️ الصوت الاحترافي للقراءة (اختياري، مرة وحدة)

بدونه، القراءة الصوتية تستخدم صوت جهاز القارئ (يختلف من جهاز لجهاز). معه، البناء يسجّل المجلة كاملة **بصوت عربي طبيعي (ليلى أو علي — لهجة بحرينية)** من Microsoft Azure، فيسمعها كل القرّاء بنفس الجودة، مع تظليل الجملة والكلمة.

**التكلفة:** الخطة المجانية (F0) فيها 500 ألف حرف شهرياً، والعدد الواحد تقريباً 33 ألف حرف. والتسجيلات تنحفظ، فإعادة البناء ما تعيد تسجيل نص ما تغيّر.

1. ادخل [portal.azure.com](https://portal.azure.com) (حساب Microsoft؛ قد يطلب بطاقة للتحقق فقط).
2. **Create a resource** ← ابحث عن **Speech** ← **Create**:
   - Region: مثلاً **UAE North** · Pricing tier: **Free F0** · سمّه مثلاً `adwaa-speech`.
3. بعد الإنشاء: **Keys and Endpoint** ← انسخ **KEY 1** و **Location/Region**.
4. في مجلد المشروع انسخ `azure.env.example` باسم **`azure.env`** وحط فيه المفتاح والمنطقة (مثل `uaenorth`). هذا الملف ما يترفع على GitHub.
5. شغّل `python tools/build.py` (أو `--skip-images`). أول مرة ياخذ تقريباً 25 دقيقة بسبب حدّ السرعة في الخطة المجانية، وبعدها ثواني.

**تغيير الصوت أو السرعة** من `issue/issue.json`:
```json
"narration": {"voice": "ar-BH-LailaNeural", "rate": "-4%"}
```
أصوات مقترحة: `ar-BH-LailaNeural` (ليلى، بحرينية) · `ar-BH-AliNeural` (علي، بحريني) · `ar-SA-ZariyahNeural` · `ar-SA-HamedNeural`.
> تجربة الأصوات قبل الاختيار: [Voice Gallery](https://speech.microsoft.com/portal/voicegallery).

## إعداد Firebase (مرة وحدة فقط، تقريباً 15 دقيقة)

### 1) أنشئ مشروع Firebase
1. ادخل على https://console.firebase.google.com بحساب Google (يفضّل حساب خاص بالمجلة أو بالقسم، مو حساب شخصي).
2. **Create a project** ← سمّه مثلاً `adwaa-magazine`.
3. Google Analytics: **أوقفه** (مو محتاجينه، وأخف على الخصوصية).
4. انسخ الـ **Project ID** اللي يظهر (مثلاً `adwaa-magazine` أو `adwaa-magazine-3f2a1`).

### 2) فعّل الدخول المجهول (لعدّاد الإعجابات)
**Build ← Authentication ← Get started ← Sign-in method ← Anonymous ← Enable ← Save**

> القارئ ما يسجّل دخول ولا يكتب أي بيانات. Firebase يعطي كل متصفح رقماً مجهولاً عشان يمنع تكرار الإعجاب.

### 3) أنشئ قاعدة البيانات
**Build ← Firestore Database ← Create database**
- الموقع (Location): اختر الأقرب، مثلاً `me-central2 (Dammam)` إذا كان متاحاً، أو `europe-west1`.
- الوضع: **Production mode** (القواعد الآمنة بنرفعها بالخطوة 6).

### 4) انسخ إعدادات الويب
**⚙️ Project settings ← General ← Your apps ← أيقونة الويب `</>`**
- سمّ التطبيق `adwaa-web` ← **Register app** (لا تفعّل خيار Hosting هنا).
- بيطلع لك كود فيه `firebaseConfig = { apiKey: ..., ... }`.
- افتح `public/firebase-config.js` وبدّل `null` بالقيم:

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "adwaa-magazine.firebaseapp.com",
  projectId: "adwaa-magazine",
  storageBucket: "adwaa-magazine.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
```

> `apiKey` في Firebase مو سر: هو معرّف عام للمشروع. الحماية الفعلية في قواعد الأمان (`firestore.rules`).

### 5) اكتب اسم المشروع في ملفين
- `.firebaserc`: بدّل `PROJECT-ID` بالـ Project ID.
- `issue/issue.json`: في `site_url` بدّل `PROJECT-ID`، وبعدها شغّل `python tools/build.py`. هذا يخلّي صورة المعاينة تطلع في واتساب ولينكدإن.
  (إذا ربطت دومين خاص لاحقاً، حط الدومين هنا بدلها.)

### 6) ارفع الموقع
تحتاج **Node.js** (نسخة LTS من https://nodejs.org). بعدها افتح Terminal داخل مجلد المشروع:

```bash
npm install -g firebase-tools
firebase login
firebase deploy
```

بعد ما يخلص يطلع لك الرابط:
**`https://PROJECT-ID.web.app`** ← هذا رابط المجلة، جاهز للمشاركة.

## تحديث أو تعديل لاحقاً
لا تعدّل `public/` يدوياً لأن البناء يعيد توليدها. عدّل `issue/issue.json` أو `tools/template.html`، شغّل `python tools/build.py`، ثم `firebase deploy`.

## الأمان: وش تحمي القواعد؟
- كل قارئ يقدر يعجب **مرة وحدة فقط** بكل موضوع، ويقدر يلغي إعجابه هو بس.
- ما أحد يقدر يضيف إعجاب باسم غيره، أو يزوّر الأرقام، أو يضيف بيانات، أو يكتب في أي مكان ثاني بالقاعدة.
- المسارات مقيّدة بصيغة محددة (`issues/{العدد}/topics/{الموضوع}/likes/{القارئ}`)، فما يقدر أحد يكتب في أي مكان ثاني. القواعد ما تحتاج تعديل مع كل عدد.
- **لا تُجمع أي بيانات شخصية**: لا اسم ولا إيميل ولا IP. يُحفظ فقط وقت الإعجاب.
- (اختياري لحماية أقوى من السبام) فعّل **App Check** مع reCAPTCHA Enterprise من لوحة Firebase.

> بما إنها مجلة جهة حكومية، يُفضّل تعرض هذا الملف على تقنية المعلومات قبل النشر.

## الحدود المجانية (خطة Spark)
| الخدمة | الحد المجاني |
|---|---|
| الاستضافة: التخزين | 10 GB (الموقع ≈ 38 MB) |
| الاستضافة: نقل البيانات | **360 MB يومياً** |
| Firestore: القراءات / الكتابات | 50,000 / 20,000 يومياً |

**النقطة الوحيدة اللي تحتاج انتباه هي النقل اليومي.** القارئ اللي يتصفح العدد كامل يستهلك تقريباً 5–8 MB، و**تحميل الـPDF وحده ≈ 9.5 MB**، يعني الخطة المجانية تكفي تقريباً **40–70 قراءة كاملة باليوم** (أقل لو كثير يحمّلون الـPDF). إذا تعدّاها، الموقع يتوقف لين اليوم الثاني.
- لو المتوقع أكثر من كذا (مثلاً يوم الإطلاق للهيئة كاملة): حوّل المشروع لخطة **Blaze** مع **Budget alert** (مثلاً 5$). الحد المجاني نفسه يظل مجاني، والزيادة تكلّف 0.15$ لكل GB. يعني ألف قارئ تقريباً أقل من دولار ونص.

## وظائف القارئ
| الوظيفة | الاستخدام |
|---|---|
| تقليب | الكمبيوتر: سحب طرف الصفحة · الأسهم · ← → في الكيبورد. الجوال والتابلت: اسحب الصفحة بإصبعك (تمشي معك)، أو اسحب بسرعة، أو اضغط على طرفها |
| صفحتين بالعرض | لف الجوال أو التابلت بالعرض تطلع صفحتين، والأشرطة تختفي تلقائياً وترجع بلمسة |
| صوت التقليب 🔊 | يشتغل تلقائياً، وزر الكتم فوق (يتذكر اختيار القارئ) |
| استمع 🎧 | يقرأ المقال من بدايته ويقلب الصفحات بنفسه، مع وقفات طبيعية بعد العناوين والفقرات. الجملة تتظلل بالأزرق والكلمة الحالية بالذهبي. اضغط على أي فقرة يبدأ منها. السرعة: 1× · 1.15× · 1.3× · 0.9×. يشتغل من أزرار السماعة وشاشة القفل في الجوال، وزر K في الكيبورد للإيقاف |
| تحميل ⬇️ | يحمّل الـPDF كامل بجودة مناسبة للشاشة (مع الروابط والنص) |
| إعجاب ♥ | في الشريط السفلي، لكل موضوع ظاهر |
| اقتباس | زر «اقتباس» ← اسحب على الجزء المطلوب، أو اضغط على صفحة لالتقاطها كاملة ← مشاركة / حفظ / نسخ |
| مشاركة | واتساب، X، لينكدإن، البريد، أو نسخ رابط يفتح على صفحة الموضوع |
| بحث | 🔍 أو Ctrl+F |
| رابط صفحة | `.../#page-20` يفتح المجلة على الصفحة 20 مباشرة |

> **عن القراءة الصوتية:** مع مفتاح Azure (القسم أعلاه) الصوت مسجّل مسبقاً ونفس الجودة لكل القرّاء. بدونه تُستخدم أفضل صوت عربي في جهاز القارئ (أفضلها Edge والآيفون والماك)، والقارئ يقدر يغيّر الصوت من زر الصوت في المشغّل.
